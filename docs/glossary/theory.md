A set of namespaces.

## Rationale

A theory in the logician's sense: a set of sentences that, together with the facts, settles every question asked of it. It sits between namespace and catalog: a set of related namespaces. It names an idea, not a mechanism. No type holds a theory, and a check never reads one.
