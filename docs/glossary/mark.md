A caller-held token naming one revision.

## Rationale

On a request a mark is a floor, asking for a revision at least that fresh. On a decision it names the revision judged. Pin fits only the second role, and seal reads oddly as a floor. Zanzibar's zookie and Kingo's kookie name the same concept. The name is proposed, not settled.
